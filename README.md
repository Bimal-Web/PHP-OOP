# PHP OOP Concepts

This repository demonstrates the core Object-Oriented Programming (OOP) concepts in PHP with simple, practical examples.

## 📂 Contents

- **classobj.php**  
  Basic class and object creation in PHP.

- **constructor-distructor.php**  
  Demonstrates constructors and destructors, showing object lifecycle.

- **excessmodifer.php**  
  Explains access modifiers (`public`, `private`, `protected`) and their usage.

- **this-keyword.php**  
  Shows how to use the `this` keyword to reference the current object.

## 🎯 Concepts Covered
- Encapsulation  
- Inheritance  
- Polymorphism  
- Abstraction  
- Constructors & Destructors  
- Access Modifiers  
- `this` keyword usage
